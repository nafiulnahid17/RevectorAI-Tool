## Faults and recovery

- **Palette color loss:** Original median-cut palette lost small crest hues. Coverage seeding plus deterministic LAB refinement fixed this locally; cache version added and 3 regression tests added. Baseline exports retained for before/after audit.
- **MPO disguised as JPG:** Wales source contains two-frame MPO. Current engine rejects it. First frame normalized to genuine JPEG with EXIF orientation; original retained. Native MPO support remains unavailable.
- **Duplicated Wales laces:** First mockup duplicated lacing on body/collar. Same-tool correction retry removed the duplicate.
- **Attached Swiss collar:** First mockup kept a collar band on the body. Same-tool correction retry removed it.
- **Small branding and mesh:** Ilves sponsor spelling and historic crest/font details remain uncertain. Brazil fine mesh and anti-aliased details are simplified. Technical vector PASS does not certify original branding fidelity.
- **Model switch unavailable:** No model selector is exposed by image_gen. Actual deterministic contour fallback tested on one sleeve in every project; live alternate AI-model fallback NOT_RUN.
- **Harness issues:** Initial report used a wrong validation field name; corrected. A geometry probe first selected an overscan/clipped shape that did not change visible pixels; probe now tests visible coordinate edits. Neither issue was bypassed or counted as PASS.
